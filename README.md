# 토마스양 (양태백) 작가 공식 홈페이지
### Thomas Yang (Taebaek Yang) Official Artist Portfolio & Art Merchandise Website

사진가, 디자이너, 융합예술가이자 문화관광학 박사인 **토마스양(양태백)** 작가의 공식 포트폴리오 및 시그니처 아트상품 웹사이트입니다.

---

## 👑 관리자 모드 (웹 화면에서 직접 사진 & 텍스트 수정 기능)

복잡한 코딩 없이 웹 브라우저 상에서 작가님께서 직접 사진을 교체하고 텍스트를 수정할 수 있는 **인라인 관리자 CMS**가 탑재되어 있습니다.

### 1. 관리자 모드 접속 방법
1. 홈페이지 우측 상단 또는 하단 푸터의 **`[🔒 관리자]`** 버튼을 클릭합니다.
2. 비밀번호를 입력합니다. (초기 비밀번호: **`1234`**)
3. 로그인 성공 시 화면 하단에 **`👑 관리자 모드 ON` 플로팅 툴바**가 활성화됩니다.

### 2. 사진 및 작품 텍스트 수정 방법
- **개별 작품/상품 수정**: 관리자 모드가 켜지면 모든 갤러리 작품 카드와 아트상품 카드 우측 상단에 **`[✏️ 수정]`** 버튼이 나타납니다.
  - `[✏️ 수정]` 클릭 팝업에서 **[📁 내 컴퓨터에서 새 사진 선택]**을 눌러 컴퓨터에 있는 실제 사진 파일을 선택하면 즉시 압축·로드되어 화면에 반영됩니다.
  - 제목, 연도, 재료/소재, 규격, 작품 설명도 직접 수정할 수 있습니다.
  - **[수정사항 저장]**을 누르면 브라우저에 실시간 반영 및 영구 저장됩니다.
- **새 작품/상품 등록**: 하단 툴바의 **`[➕ 새 작품 등록]`** 또는 **`[➕ 새 아트상품 등록]`** 버튼을 눌러 언제든 새로운 작품을 원하는 장르에 추가할 수 있습니다.
- **작가 프로필 수정**: 하단 툴바의 **`[✏️ 프로필 수정]`** 버튼을 눌러 작가명, 대표 직함, 예술관 슬로건, 소개글(Bio)을 직접 수정할 수 있습니다.
- **비밀번호 변경**: 하단 툴바의 **`[🔑 암호 변경]`** 버튼을 통해 관리자 비밀번호를 원하는 번호로 변경할 수 있습니다.

### 3. 수정한 내용을 영구 반영 (다운로드)
- 웹사이트에서 수정한 모든 내용은 브라우저(LocalStorage)에 실시간 자동 저장되므로 새로고침해도 그대로 유지됩니다.
- 다른 컴퓨터나 모바일 기기, GitHub Pages 배포 사이트에도 영구히 반영하고 싶으실 때는 하단 툴바의 **`[💾 data.js 다운로드]`** 버튼을 누르시면 수정된 데이터 파일(`data.js`)이 1초 만에 다운로드됩니다.
- 다운로드된 `data.js` 파일을 프로젝트 폴더의 `js/data.js` 파일에 덮어씌워 주시면 됩니다.

## 🎨 주요 메뉴 및 구성

1. **프로필 (Profile)**
   - 작가 소개, 예술관(빛과 수묵의 서사)
   - 학문적 배경(문화관광학 박사, 신문방송학·창업학·한국어 석사 등)
   - 주요 약력 (2021 중국 이우 칠묵미술관 100점 완판 〈빙호영월〉 초대전, 진화시 양태백 미술관 건립 추진 등) 및 수상 경력

2. **갤러리 (Gallery)**
   - **메뉴 클릭 시 서브메뉴(9개 장르) 즉시 노출 및 필터링:**
     - 📷 **사진 (Photography)**: 파인아트 빛과 하늘의 서사
     - 🎬 **영상 (Video)**: 4K 미디어 아트 & 비디오 인스톨레이션
     - 🎨 **회화 (Painting)**: 대지의 호흡 혼합재료 대작
     - ⛰️ **운무산수 (Cloud & Mist Landscape)**: 태백산 운무도, 몽유운산
     - 🌸 **문인화 (Literati Painting)**: 청향묵란, 군자묵죽
     - ✍️ **서예 (Calligraphy)**: 빙호영월(氷壺迎月), 상선약수(上善若水)
     - 🧵 **텍스타일 (Textile Art)**: 한지와 생사의 유영, 천연 쪽염색
     - 🏺 **도자기 (Ceramics)**: 현대 비색 청자 매병, 분청사기 귀얄 철화문
     - 🏛️ **설치미술 (Installation Art)**: 시공간의 묵향, 영겁의 문

3. **아트상품 (Art Merchandise)**
   - **메뉴 클릭 시 서브메뉴(5개 라인) 즉시 노출 및 필터링:**
     - 👔 **넥타이 (Neckties)**: 수묵 운무산수 실크 자카드 타이, 훈민정음 서예 타이
     - 🧣 **스카프 (Scarves)**: 빙호영월 실크 트윌 스카프 (90x90cm), 연화 롱 스카프
     - 🍵 **청자도자기 (Celadon Ceramics)**: 비색 청자 5인 다기 세트, 운학문 음각 화병
     - ☂️ **양산 및 우산 (Parasols & Umbrellas)**: 운무산수 3단 초경량 UV 암막 자동 양우산, 문인화 양산
     - 🎁 **관광상품개발 (Tourism Souvenirs)**: K-헤리티지 문화관광상품 브랜딩 솔루션, 전통 한옥 트래블 기프트

4. **언론 및 평론 (Press & Critiques)**
   - 중국 칠묵미술관 100점 완판 보도
   - 미술평론가 정진우 박사의 심층 평론 ("얼음 항아리에 달을 담다")
   - 월간 미술세계 작가 심층 인터뷰

5. **앨범 (Album)**
   - 전시회 개막식 리셉션 현장, 아틀리에 작업 풍경, 해외 문화교류 협약식 사진 아카이브

## 💻 기술 스택 및 구조

- **Frontend**: 순수 HTML5, 모던 CSS3 (Flexbox/Grid, CSS Variables, 반응형 모바일 최적화), Vanilla JavaScript (ES6+)
- **In-Browser CMS**: HTML5 File API + Canvas 이미지 자동 압축 + LocalStorage 영구 보존 + 원클릭 data.js 내보내기
- **No Build Required**: 별도의 복잡한 백엔드 설치 없이 `index.html`을 바로 열거나 GitHub Pages로 원클릭 배포 가능
- **Typography**: Google Fonts (Noto Serif KR, Noto Sans KR, Cinzel, Cormorant Garamond)

## 🚀 로컬 실행 방법

브라우저에서 `index.html` 파일을 더블 클릭하여 바로 열거나, 로컬 서버를 실행하여 확인할 수 있습니다.

```bash
# Python 3 내장 웹서버 실행
python3 -m http.server 8000
```
실행 후 브라우저에서 `http://localhost:8000` 접속

## 🌐 GitHub Pages 배포 방법

이 저장소는 GitHub Pages를 통해 무료로 즉시 호스팅할 수 있습니다:
1. 저장소의 `Settings` > `Pages` 이동
2. `Source`에서 `Deploy from a branch` 선택
3. `Branch`를 `main` / `/(root)`로 지정 후 `Save`
4. 수 분 내로 배포 완료 URL 생성 (예: `https://thomasyang263956-ship-it.github.io/thomasyang/`)
